# Amazon S3

> Source: [Amazon S3 101](https://psychedelic-cuticle-e74.notion.site/Amazon-S3-Simple-Storage-Service-101-27e12f4a7f5045c3962d335903f0f1d8)

## Core idea

S3 is AWS’s scalable **object storage** service. Data is stored as objects inside buckets. It is not a file system or block device.

## Remember

- **Object** = data (value) identified by a **key**; it can also carry metadata. An object must belong to a bucket.
- **Bucket** = container for objects. A bucket is created in a region, and its data stays there unless you configure it to move or replicate elsewhere.
- Objects can be up to **50 TB** each. A bucket can contain an unlimited number of objects.
- Use S3 for large datasets and unstructured data. Use EFS/FSx for file storage and EBS for mountable block storage.
