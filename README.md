# BR9 Notes

Concise course notes published as a searchable Quartz website.

## Website

Once GitHub Pages is enabled with **Settings → Pages → Source: GitHub Actions**, the site will be available at:

https://sabersmash1412.github.io/notes/

## Notes

- `SWE.md` — Software Engineering
- `OOP-Java.md` — Object-Oriented Programming and Java
- `docs/networking/` — Computer Networks and the OSI Model
- `docs/aws/` — seven concise AWS service notes

The build copies these sources into Quartz's generated `content/` directory before rendering.
